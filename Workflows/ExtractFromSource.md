# ExtractFromSource

Use this workflow when a reel, demo, or creator video contains a tool stack that should become a reusable workflow.

## Steps

1. Strip the source down to explicit tool and output claims.
2. Separate research tools from browser capture and downstream orchestration.
3. Preserve quoted source evidence in `ReelEvidence.md`.
4. Rewrite the implementation layer into agent-executable steps.
5. Document the blocked-state taxonomy and resume rules.
